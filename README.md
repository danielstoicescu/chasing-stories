# Chasing Stories — website

Deschide **`Chasing Stories - site.html`** (dublu-click). E pagina completă, cu toate pozele înăuntru.

Nu deschide fișierele din `src/` — sunt sursele; singure arată doar header și footer.

- `src/` — shell.html, styles.css, data.js (conținut: proiecte, poze, filme), app.js (router, pagini, pixeli WebGL)
- `assets/` — imaginile web (WebP) + logo-uri clienți
- `python3 build.py` — reconstruiește `dist/index.html` și fișierul de mai sus
- `python3 prep_assets.py` — trage imaginile alese din Drive
